## 1. What the change does

Changes the error a client sees when a suggester was never built or loaded on the node that answers. The branch does not add replication.

- `SolrSuggester.getSuggestions` wraps the lookup in a `try` (`SolrSuggester.java` line 231). It catches `IllegalStateException` (line 232) and rethrows `SolrException(SERVICE_UNAVAILABLE)` (lines 233-243). The message names the suggester, says it "is not built on this node", includes the original message, and gives the workaround: build on every node (`suggest.build` or `suggest.buildAll`) or enable `buildOnStartup` or `buildOnCommit`. The message also states that "Suggester dictionaries are not replicated". The lookup body moved to a new `lookupSuggestions` method (line 246). **[verified: code]**
- Test: `TestFreeTextSuggesterNotBuilt` (58 lines, new). A query before any build must return 503 with "is not built on this node". After `suggest.buildAll` the same query returns one suggestion. It uses the existing `solrconfig-phrasesuggest.xml` fixture (`free_text_suggest`, `FreeTextLookupFactory`). **[verified: diff]**
- Changelog, type `fixed`: a suggester never built on a node "now answers 503 with a message that says so, instead of a bare IllegalStateException".

The reported case is FreeTextLookupFactory, built with `suggest.buildAll` on one replica, with queries routed to other replicas failing with `Lookup not supported at this time`.

## 4. Blockers

1. **Owner call: does a clearer error resolve this ticket?** The title asks for replication to work. The maintainer comment says suggesters never replicated, so the expected fix is a workaround and documentation. The branch takes that position (replication "is NOT attempted", per the handoff) and changes only the error. The owner decides one of three resolutions: keep the error change, add ref-guide documentation (which the branch does not include, and the reporter says the docs were not findable), or close the ticket with the comment as the answer. **[verified: record]** for the comment; the decision is the owner's.
2. **Defect risk: the catch is broader than the case it targets.** The `catch (IllegalStateException e)` at line 232 applies to every suggester lookup, not only FreeText. Any `IllegalStateException` from the lookup path becomes a 503 that says the suggester "is not built on this node". Solr's own `org.apache.solr.common.AlreadyClosedException` extends `IllegalStateException` (`solr/solrj/src/java/org/apache/solr/common/AlreadyClosedException.java:20`, at upstream/main). `SolrSuggester` also imports Lucene's `AlreadyClosedException` (line 40), and the build path handles it (lines 177-181). If a suggester's lookup is closed during a core reload while a request is in flight, that case would be reported as "not built". Whether Lucene's `AlreadyClosedException` extends `IllegalStateException` was not checked here (no Lucene source in this checkout). **[hypothesis]** for the Lucene class; **[verified: code]** for the Solr class and the catch. Narrow the catch to the FreeText case, or exclude `AlreadyClosedException`, before the draft.
3. **Choice: HTTP status change.** Affected requests move from 500 to 503. Clients and monitoring that key on 500 see a change. The owner decides whether that is acceptable for this ticket.
4. **Unverified premise: other lookups.** The handoff guesses that Analyzing and Fuzzy lookups return empty results when unbuilt, so the branch "should not change them". Because the catch is on `IllegalStateException` for all lookups (item 2), that guess matters. It is not checked. **[hypothesis]**.
5. **Unverified premise: the test's expectation.** The handoff lists as guesses that `FreeTextSuggester.lookup` throws ISE before any build or load, that `assertQEx` with an `ErrorCode` matches the message substring, and that `SuggestComponent` does not already catch the ISE higher up. None was run. The ticket's stack trace supports the first. **[hypothesis]**.
