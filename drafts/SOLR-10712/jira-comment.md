We re-checked this ticket at fork commit 498a09aea97. The SolrJ update request writer now marshals the request directly to the output stream (JavaBinRequestWriter.getContentWriter), so the buffered in-memory copy described in the ticket is gone. The change came in with SOLR-18351 (commit 78862e7f54), which is on main at this commit. We are treating the ticket as fixed by that change, linked by code path; we have not measured client memory use.
