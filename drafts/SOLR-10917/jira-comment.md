We re-checked this ticket at fork commit 498a09aea97. Forwarded requests are now capped at the total number of replicas in the collection (HttpSolrCall.java), added in SOLR-13793 (commit b8648c60e7), which also adds a test for querying a down collection. A request for a collection with no active replicas stops after that limit instead of bouncing between nodes, which is the forwarding loop the ticket describes. We have not run the down-collection test in this pass, so this is a code-path match. We are treating the ticket as fixed by that change.
