The test mock used by the PKI authentication integration test accepts a request with no principal on unprotected resources, and returns 403 rather than 401 on protected ones. That is why the test cannot catch a request that loses its principal. The change this issue asks for is a small test-only change: the mock returns 401 when there is no principal, plus a test case that checks it. We have not yet run that test on the current mock, so the draft carries the test case for that check.
