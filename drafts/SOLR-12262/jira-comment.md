We re-checked this ticket at fork commit 498a09aea97. The details call no longer returns a previous backup's status while a new backup runs: SnapShooter reports the in-progress status synchronously when a backup is requested (SnapShooter.java createSnapAsync), which replaces the stale value. The change came in with SOLR-18344 (commit 0a0c25046e), which is on main at this commit. The ticket can be closed as fixed by that change; the regression test is TestSnapshotCoreBackup.testBackupReportsProgressWhileRunning.
