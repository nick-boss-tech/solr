We re-read this ticket against the Solr source at fork commit 498a09aea97. The default for the sow parameter is still false (QueryParser.java), so a term like test3 is analyzed as a sequence and produces term clauses rather than a phrase, as the ticket reports. The standard query parser guide documents sow and its default, and sow=true restores the earlier behavior. Whether the default should change is a maintainer decision, so this ticket stays open.
