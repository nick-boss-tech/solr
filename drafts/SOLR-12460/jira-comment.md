We re-read this ticket against the Solr source at fork commit 498a09aea97. The join domain query in JSON facets is still cached in the filterCache under a key built from the base docset (FacetProcessor.handleJoinField and FacetRequest.JoinField.createDomainQuery), so the reported cache behavior is consistent with the code. We have not run a multi-shard reproduction, and whether such domain queries should be cached is a design question, so this ticket stays open.
