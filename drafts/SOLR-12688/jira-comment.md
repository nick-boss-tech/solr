We checked this umbrella ticket against the current code. Pure DocValues support (SOLR-12697) and the immutable model with cached hash code (SOLR-12699) are on main. The performance change for fields that are both stored and DocValues (SOLR-12698) has no commit on main, and the test suite refuses multi-valued DocValues fields on purpose, so that is a design decision. We are leaving the umbrella open for those two points.
