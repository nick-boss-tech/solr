We checked this ticket against the current code. The facet heatmap geom argument is still parsed only as WKT or as the rectangle syntax, so a GeoJSON geometry is not accepted there; GeoJSON is supported for indexing, which is a different path. Adding GeoJSON input is a design choice with open questions on this ticket (how to parse it without the deprecated JTS method, and the envelope type), so we are leaving the ticket open for a maintainer decision. A run with a GeoJSON polygon in the geom argument would confirm the error at the current head.
