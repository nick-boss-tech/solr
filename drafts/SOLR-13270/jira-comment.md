We checked this ticket against the current code. The Apache HttpClient client that set the request configuration in this ticket was moved out of the main Solr tree in SOLR-17962, and the clients that ship now (the JDK client and the Jetty-based clients) do not set an Expect header. The code path the ticket describes is therefore no longer present, so we are closing the ticket as obsolete for that client. Whether the current clients should send "Expect: 100-continue" is a separate request and would need its own ticket.
