We checked this ticket against the current code. The ZooKeeper connect timeout is configurable: the client has a setter (ZkClientClusterStateProvider.setZkConnectTimeout), and the default can be set with the system property solr.zookeeper.client.connect.timeout. The environment variable this ticket asks for is not in the Solr scripts. We are leaving the ticket open for a decision on whether that variable should be added or the ticket closed as satisfied by the setter and property.
