We checked this ticket against the current code. The embedded test server (JettySolrRunner) now adds the HTTP/2 connection factory outside test mode as well, as part of SOLR-15428 (commit 890ef78421). The connector used outside test mode has no TLS, so the HTTP/2 it offers is cleartext (h2c) rather than the TLS form that test mode can configure. We are closing this as fixed. If embedded Solr still fails to speak HTTP/2 in your setup, please reopen with the Solr version and the client you use.
