We reviewed this ticket against the current code. The standalone similarity search reads the term vectors of the source document, and the cloud version reads the stored field values, so a field that is indexed but not stored gives different results on the two. There is no option to choose the source. We are leaving the ticket open for a decision on the name and default of such an option. A useful next step is the field definitions you use (stored and indexed flags) and the query you run on each mode.
