We reviewed this ticket against the current code. V2 requests are now reported with the public API path, and the audit event maps the V2 collection paths to their collections. The request body is not recorded: the audit event has no body field. Recording a body can expose credentials or other sensitive data, so we are leaving the ticket open for a decision on what body content should be logged. A useful next step is the request types you need to audit with their body content, so the decision can be scoped.
