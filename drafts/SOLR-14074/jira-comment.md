We reviewed this ticket against the current code. Collapse is refused on purpose when grouping is enabled, a change made in 2019 (SOLR-13970), so the combined request is not processed at all. Making the two work together would mean resetting the collapse caches between the grouping passes, and that is a feature decision we have not made. We are leaving the ticket open for that decision. A useful next step is the query shape you need (grouping and collapse together) so the use case can be weighed.
