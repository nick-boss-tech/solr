Raw query values that begin with "{!" are still read as local params on current main, so the raw parser does not receive them directly. A dereferenced value (for example v=$param) avoids that. We have not yet confirmed the failure on a current build, and the option this ticket proposes, enableLocalParams, is not in Solr. We are keeping this issue open until someone confirms the failing query on current main and a decision is made on whether the option is wanted. If you still see this, please attach the query and the Solr version.
