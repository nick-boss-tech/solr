On current main a replication that changes both the index and the configuration installs the new index first, and reloads the core with the new configuration after that. Between the two steps, searches use the old configuration on the new index. Changing that order is a replication design decision, and we have not measured how large the window is. We are keeping this issue open for that decision and for a measurement. If you have seen a search error caused by this window on a current release, please attach the logs.
