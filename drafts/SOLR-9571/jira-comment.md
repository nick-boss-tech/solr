On current main the load-balancing client no longer reports a time-limit expiry as "no live servers": it reports that the processing limits for the request were exceeded, with the earlier error as the cause. It still does not return a partial results response on the client side. Whether it should is a design choice, so we are keeping this issue open for that decision. If you still see the misleading message on a current release, please attach the request and the exception.
