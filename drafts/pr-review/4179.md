## Summary of the change

Moves the core split and collection shard split v2 APIs from `@EndPoint`/`@Command` to JAX-RS, and moves their logic out of v1 (`SplitOp`, `CollectionsHandler`) into the v2 classes (`SplitCoreAPI`, `SplitShardAPI`), following the RenameCore, CreateShard and DeleteShard pattern. Adds request and response model classes, tests, a changelog entry and ref guide text in `coreadmin-api.adoc`.
