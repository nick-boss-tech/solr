## Summary of the change

Adds a standalone external-consumer project, `test-external-client/` (a Maven `pom.xml`, a Gradle `build.gradle.kts` and settings, a README, and `DependencySmokeTest.java`), that builds against the published `solr-solrj` and `solr-test-framework` POMs with no Solr source tree around it. Adds `dev-tools/scripts/checkTestExternalClient.py` (117 lines) to drive it, and refactors `dev-tools/scripts/smokeTestRelease.py` around `checkMaven`, adding `prepareExternalClientProject` and `_linkOrCopy`. Adds a changelog entry (`type: other`).

## Proposed comments

1. Release-script change. `smokeTestRelease.py` is used to verify release candidates, so its refactor needs a release manager's review. Could the PR say which existing checks behave the same as before, and show one run of `smokeTestRelease.py` against a candidate or a local snapshot, so the release manager can see the new step does not change the old ones?
2. Version coupling. The external project's `pom.xml` and Gradle file pin a Solr version. If that is a fixed number, the project will not test the version being released. Could the PR say how the version is set at release time (a property filled by the script, or read from `gradle.properties`)?
3. Dependency on the repo wrapper. `prepareExternalClientProject` copies the repo-root Gradle wrapper into the work directory. Please confirm that the copied wrapper is the same version as the repo's, and that no unrelated repo files are pulled in.
4. Hard links. `_linkOrCopy` hard-links files and falls back to copy on `OSError`. The fallback is correct, but a comment should say why hard links are used (speed on large trees) so a later reader does not remove them.
5. Changelog. `type: other` fits a build and release-tooling change. Nothing user-facing changes, so the entry can stay short.
6. Test quality. `DependencySmokeTest` checks that a few classes resolve from the published jars. It would help to say in the class Javadoc what it does not cover, so the smoke test is not read as a full API test.
