- Why: the default JSON writer (`JacksonJsonWriter`) returns HTTP 500 for `json.nl=arrntv` whenever the response holds a plain NamedList, such as facet data or terms statistics. The change routes arrntv requests to the legacy `JSONResponseWriter`, and it fixes the legacy NTV writer so that a NamedList or SimpleOrderedMap used as an element value is written with type `lst` instead of invalid JSON. Without the second part, the first part would turn the 500 into a 200 with invalid JSON. No receipt exists for this ticket yet.
