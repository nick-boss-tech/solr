# SOLR-17849: Implement Index & Query section header (new UI)

Draft PR description. Not opened as a GitHub PR. Partial: the header and the request form are hosted on the Configsets Index / Query tab, with data loading. Configsets > Files is not part of this change.

## What

- `IndexQueryHeader`: a collection dropdown and a request handler dropdown. The handler dropdown shows each endpoint name with its class. Both are disabled while loading and when there is nothing to pick. Messages show when there are no collections or a collection has no handlers.
- `IndexQueryStateHolder` and `HttpIndexQueryRepository`: load collections from `GET api/collections`, handlers from `GET api/collections/{c}/config/requestHandler`, and run a request against `GET solr/{c}{handler}`.
- `IndexQueryContent`: the header, the request form from SOLR-17850, and the response as selectable monospace text. The header and form appear on the Index / Query tab under Configsets.
- Route change: selecting a Configsets tab now switches the content. Before, every tab showed the Overview. Files, Schema, Update Configuration, Handlers, and Search Components show an empty area until they are built.

## Layout limit

The Configsets content area gives its children an unbounded height. A lazy list and a vertical scroll both failed there, so the screen is a plain column and the form does not scroll on its own. Long responses scroll horizontally. A follow-up should bound the Configsets content (in `ConfigsetsContent.kt`, the `FlowRow` that hosts the navigation display) before the form gets a vertical scroll.

## Not in this change

- Configsets > Files. The baseline has no configset file-listing API, so the file tree (SOLR-17887) and viewer (SOLR-17911) cannot be fed yet.
- The request and response previews the ticket excludes.

## Testing

- `IndexQueryStateHolderTest` 5 of 5, `IndexQueryHeaderTest` 5 of 5, `SearchHandlerFormTest` 6 of 6, `IndexQueryContentTest` 2 of 2 on the software renderer (see `material/ui-test-setup/`).
- `:shared:spotlessCheck` passes.
- Browser smoke on a Solr 11.0.0-SNAPSHOT node built from c8ab71430f: the header loads `smoke`, lists its handlers, the form appears for `/select`, and a `q=*:*` request returns the JSON response. The earlier blank-content failure came from a vertical scroll in the content, and is fixed.

## Blast radius

Not flagged. Layout, state, and HTTP GET calls to existing endpoints. No Canvas, DrawScope, graphicsLayer, or shaders.
