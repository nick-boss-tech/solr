# SOLR-17849: Implement Index & Query section header (new UI)

Draft PR description. Not opened as a GitHub PR. Partial: this is the header component only.

## What

Adds `IndexQueryHeader`, a composable in `ui/shared` with a collection dropdown and a request handler dropdown.

- The collection dropdown lists the collections given to it. Both dropdowns are disabled while collections load, and the collection dropdown is disabled when there are none.
- The request handler dropdown is disabled until a collection is selected, and while that collection's handlers load.
- Each request handler shows its endpoint name, with its class below it. Long class names are cut with an ellipsis.
- A message appears when there are no collections, and when the selected collection has no request handlers.
- The component reports selections through `onSelectCollection` and `onSelectHandler`. It does not hold selection state; the caller does.

## Not in this change

- Placing the header on a screen. The Index / Query tab under Configsets has no content scene, so there is nowhere to host it yet. That is a follow-up.
- Loading the collections and the handlers.
- Placeholder text: the request handler placeholder ("Select a request handler") shows while the field is focused, which is the standard Material 3 behavior. It is not shown on an unfocused empty field.
