# SOLR-17909: Implement a Breadcrumb Navigation Component (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds `Breadcrumb`, a reusable composable in `ui/shared`. The caller gives an ordered list of labels.

- The last label is the current location. It is shown but not clickable.
- Each earlier label is clickable and reports its index through `onItemClick`.
- Labels are separated by ">".

## Criteria change

The JIRA criteria mention the Decompose childstack. The baseline removed Decompose, so the component takes its items from the caller and has no navigation dependency. The claim `pool-ui-SOLR-17909` lists the rewritten criteria. Confirm them before merge.

## Not in this change

Using the component in the Collections section. That section is not built yet, so the component has no caller.
