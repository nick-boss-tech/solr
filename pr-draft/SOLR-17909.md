# SOLR-17909: Implement a Breadcrumb Navigation Component (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds `SolrBreadcrumb`, a reusable composable in `ui/shared` that shows a trail of labels. Earlier entries are clickable and report their index, so the caller can navigate back to that layer. The last entry is the current selection: highlighted and not clickable. The trail wraps onto the next line when the width is not enough.

The ticket asked for the breadcrumb to be built from the Decompose child stack. Decompose was removed from the shared module in `c8ab71430f` (SOLR-19xx migration, #4929), so this change takes a plain list of entries and a callback. Hooking it to a navigation stack, and to the Collections section, is a follow-up.

## Relation to the earlier branch

`solr-17909-breadcrumb` on the fork (`fdb53f6a02`, 2026-10-19) already has a `Breadcrumb` composable with three tests. It lays the trail out in one row, so it does not wrap, which the ticket asks for. This change keeps the same behavior (earlier entries clickable, last entry inert) and adds wrapping, a test for it, and a preview. It is pushed to a separate branch so the earlier branch is left as it is.
