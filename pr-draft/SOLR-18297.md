# SOLR-18297: upgrade Jetty to 12.1.14

Draft PR description. Not opened as a GitHub PR.

## Change

- `gradle/libs.versions.toml`: `eclipse-jetty` 12.1.12 to 12.1.14.
- Gradle lock files regenerated with `resolveAndLockAll --write-locks`.
- License entries: the 27 `jetty-*-12.1.12.jar.sha1` files renamed to 12.1.14 by `updateLicenses`.

## Route and tradeoffs

- Chosen: a version bump only, with no code changes. The compile gate passed without any migration edits, so the breaking changes listed in the Jetty 12.0 to 12.1 migration guide do not touch Solr's code paths that compile here.
- Not done: the ticket's wider migration work (21 comments in JIRA describe the breaking changes). A compile is not a behavior check; runtime differences in HTTP handling would show up only in a full test run.

## Gate

- `:solr:core:compileTestJava :solr:server:compileJava` passes.
- `:solr:core:test --tests org.apache.solr.cli.StatusToolTest` passes, 1 of 1 (starts a Jetty-backed server).
- Not run: the full core and server test suites, which a pool gate host must run before merge.

## Blast radius

Not flagged for GL. The change is server and client HTTP library code. The HTTP layer changes in a minor release, so a full suite run is required.
