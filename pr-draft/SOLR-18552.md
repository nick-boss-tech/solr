# SOLR-18552: default MMapDirectory.sharedArenaMaxPermits to 64 in bin/solr (9.x)

Draft PR description. Not opened as a GitHub PR.

## Change

`bin/solr` adds `-Dorg.apache.lucene.store.MMapDirectory.sharedArenaMaxPermits=64` to the launcher options, after the stack size default. The 9.x default is 1024. The ticket cites 64 as the better default (true for Lucene 10.x).

## Route and tradeoffs

- Chosen: launcher default only. Users who start Solr with their own command line, or embed Solr, keep the Lucene default. A user can still override it by setting the property.
- Not chosen: changing Lucene's default in code. That is a library change and reaches embedded users too; a separate decision.
- Scope: 9.x only, per the ticket. The main branch is on Lucene 10, where the ticket says 64 is already the value; this branch does not touch main.

## Gate

- Launcher gate: `bin/solr start -p 8995` from a 11.0 SNAPSHOT distribution with this bin/solr copied in. One JVM carries the property. The control launcher (unmodified) gives zero. The 9.x distribution build could not run here (the JS client npm step fails on this host; branch_9 has no switch for it), so the gate used an 11.0 distribution for the launcher behaviour only.
- Not gated: the 9.x distribution build and `bats` launcher tests. Those need a pool gate host.

## Blast radius

Not flagged. Startup option only.
