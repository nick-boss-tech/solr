Title: Document the Japanese tokenizer's compound option and its synonym interaction

https://issues.apache.org/jira/browse/SOLR-16914

## What happens today

**The Japanese tokenizer section does not say which tokens the compound option keeps, or what that does to a Synonym Graph Filter placed after the tokenizer.**

The section says that search mode keeps compound terms "as synonyms", but it does not name the option that controls this. Its option table gives `discardCompoundToken` no default. The [Synonym Graph Filter section](https://github.com/nick-boss-tech/solr/blob/cd878023d3d0e351700f5365f692423fbe97d972/solr/solr-ref-guide/modules/indexing-guide/pages/filters.adoc#L3131) already says that the filter cannot consume an input token graph correctly, so the missing link matters.

## What this change does

**The change names the option, gives its default, and says when synonyms need `normal` mode.**

- The tokenizer description names `discardCompoundToken="false"` as the setting that keeps the original compound terms ([line 2292](https://github.com/nick-boss-tech/solr/blob/cd878023d3d0e351700f5365f692423fbe97d972/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L2292)).
- A new paragraph under the mode list ([lines 2315-2317](https://github.com/nick-boss-tech/solr/blob/cd878023d3d0e351700f5365f692423fbe97d972/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L2315-L2317)) says that with the default `true`, `search` and `extended` emit only the parts of each compound, so the tokens form a linear stream. With `false`, the original compound is kept as well. In an analyzer that applies synonyms after this tokenizer with `false`, use `normal` mode.
- The option table gives `discardCompoundToken` the default `true` ([line 2351](https://github.com/nick-boss-tech/solr/blob/cd878023d3d0e351700f5365f692423fbe97d972/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L2351)) and limits it to `search` and `extended` ([line 2354](https://github.com/nick-boss-tech/solr/blob/cd878023d3d0e351700f5365f692423fbe97d972/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L2354)).

The defaults match the Lucene Kuromoji factory, which Solr main pins at Lucene 10.4.0. branch_9x pins Lucene 9.12.3; those defaults were not checked, so this change is for main.

## Limits

The reporter's chain uses the tokenizer's default settings, so the new text does not explain that failure. The change is guidance on how the compound option interacts with synonym filters.
- The option table still gives `mode` no default (line 2302), although search is the default. This change does not touch that row.
- The statement that `false` gives a non-linear stream follows the tokenizer's description that the compound is kept as a synonym. A token stream check was not run.
