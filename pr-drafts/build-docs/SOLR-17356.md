## What happens today

**The Ukrainian section says the Lucene jar contains the dictionary, and the current jar does not.**

The page says the `lucene-analyzers-morfologik` jar contains a Ukrainian dictionary at `org/apache/lucene/analysis/uk/ukrainian.dict` ([language-analysis.adoc L3480, base commit](https://github.com/nick-boss-tech/solr/blob/b6b2b8f10e9827e3b86e44649fb7966ce646c185/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L3480)). Solr main uses Lucene 10.4.0. The published `lucene-analysis-morfologik` 10.4.0 jar has the Ukrainian stopword list but not that dictionary. So the dictionary path the page gives does not resolve with the stock module.

## What this change does

**The Ukrainian section names the external dictionary library and the path that library provides.**

The section now says the dictionary comes from the `morfologik-ukrainian-lt` library, which the user adds to the `analysis-extras` classpath, for example in its `lib` directory. The dictionary is then found at `org/languagetool/resource/uk/ukrainian.dict` ([L3480-L3482, head](https://github.com/nick-boss-tech/solr/blob/9fe2801de07c0e12bc7b066221e4f59c2ebd7d9d/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L3480-L3482)). Both filter examples use that path ([L3497](https://github.com/nick-boss-tech/solr/blob/9fe2801de07c0e12bc7b066221e4f59c2ebd7d9d/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L3497), [L3511](https://github.com/nick-boss-tech/solr/blob/9fe2801de07c0e12bc7b066221e4f59c2ebd7d9d/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L3511)). The jar name is corrected to `lucene-analysis-morfologik` ([L3466, head](https://github.com/nick-boss-tech/solr/blob/9fe2801de07c0e12bc7b066221e4f59c2ebd7d9d/solr/solr-ref-guide/modules/indexing-guide/pages/language-analysis.adoc#L3466)).

The change edits the reference guide and adds a changelog fragment. It does not change any code.

## Proof

**No test ran, because this change is documentation only. The evidence is a documentation build, a changelog check, and a check of the library contents.**

- The reference-guide build (`:solr:solr-ref-guide:buildLocalSite`) passed at head 9fe2801de07, verified 2026-10-11: 69 tasks, 59 executed and 10 up-to-date. The rendered Ukrainian page contains `morfologik-ukrainian-lt`, the dictionary path, and the Ukrainian stopword resource.
- The changelog check (`logchangeLint`) passed at the same head.
- Library contents: the Lucene 10.4.0 Morfologik jar has the stopword resource but no `ukrainian.dict`. The `morfologik-ukrainian-lt` 4.4.4 jar has `org/languagetool/resource/uk/ukrainian.dict` and its `.info` file. So the new path resolves only after the library is added, as the page now says.
- The build compiles Java code as a prerequisite, but no Java test task ran.

## Limits

**The dictionary is an external library. Solr does not ship it, and the page now says so.**

Adding the library to `analysis-extras` as a dependency, so that the dictionary works without a manual step, is not part of this change. A follow-up for that can be opened on request.

The library check covers Lucene 10.4.0, the version Solr main uses. Other Lucene versions were not checked.
