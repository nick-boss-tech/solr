## What happens today

**The faceting guide says filter exclusion works for every facet type, but it does not say where `ex` goes for interval facets.**

The guide states that "Filter exclusion is supported for all types of facets" ([faceting.adoc, line 848 at the merge base](https://github.com/nick-boss-tech/solr/blob/cabedd1d968059215188f4e7563fb303241899ed/solr/solr-ref-guide/modules/query-guide/pages/faceting.adoc#L848)). The ticket reports that tag and exclude local params do not work for interval facets as the guide describes them. A user who puts `ex` on an interval set item, `facet.interval.set`, gets no exclusion, because only `key` is read from that item. The working form puts `ex` on `facet.interval`. The guide does not say so.

## What this change does

**The Interval Faceting section now says where `ex` goes, with an example.**

The new paragraph says that `ex` applies to the whole interval facet, so it goes in the `facet.interval` parameter. It says `facet.interval.set` reads only `key` ([faceting.adoc, lines 816-818 at the head](https://github.com/nick-boss-tech/solr/blob/af336af5ab8aa03b95cc6ecf0fde565ef305ca12/solr/solr-ref-guide/modules/query-guide/pages/faceting.adoc#L816-L818)). The example tags a filter on `weight` and passes `{!ex=weight}` on `facet.interval` ([lines 820-826](https://github.com/nick-boss-tech/solr/blob/af336af5ab8aa03b95cc6ecf0fde565ef305ca12/solr/solr-ref-guide/modules/query-guide/pages/faceting.adoc#L820-L826)). The change is documentation only. No code changes.

## Limits
