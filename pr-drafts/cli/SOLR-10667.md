## What happens today

**The full Solr distribution does not include the Learning To Rank example files.**

The packaging task copies each module's files into the distribution, but it has no step for a module's `example` directory. Only the Learning To Rank module has one today. It holds seven tracked files, among them config.json, train_and_upload_demo_model.py and exampleFeatures.json, and none of them reaches the distribution.

Pre-change code, at the base commit (the merge-base): [gradle/solr/packaging.gradle lines 80-83](https://github.com/nick-boss-tech/solr/blob/cabedd1d968059215188f4e7563fb303241899ed/gradle/solr/packaging.gradle#L80-L83).

## What this change does

**The packaging task now copies each module's `example` directory into the distribution.**

The change adds one `from` block to the packaging task, which copies the module's `example` directory to `example` in the distribution: [gradle/solr/packaging.gradle lines 83-85](https://github.com/nick-boss-tech/solr/blob/1e3f022552be4d281a020e015f4c8c05ce4eec6c/gradle/solr/packaging.gradle#L83-L85).

Every file in the directory is copied, including its `.gitignore` and `README.md`. The copy applies to every module, so a module that adds an example directory later ships it too.

## Proof

**The distribution now has the example files, and the new packaging check passes.**

A distribution assembled from the base commit, with the packaging file unchanged, has `modules/ltr` but no `modules/ltr/example`. The same assembly at this head has `modules/ltr/example`, with `config.json`, `train_and_upload_demo_model.py` and `exampleFeatures.json`.

The new check is "ltr module ships its example directory" in [solr/packaging/test/test_modules.bats lines 42-47](https://github.com/nick-boss-tech/solr/blob/1e3f022552be4d281a020e015f4c8c05ce4eec6c/solr/packaging/test/test_modules.bats#L42-L47):

- Head distribution: 1 test, 0 failures.
- This head: 1 test, 0 failures.

Verified 2026-10-10 at head `1e3f022552be`. The distribution was assembled with the full-distribution install task. No Java code changed, so no Java test ran.

## Limits

**The check covers file presence in the full distribution only.**

- The check looks for three file names. It does not run the example's scripts or check their contents.
- No check covers a module that adds an example directory later.
- The Learning To Rank reference page still says the example folder is not shipped in the binary release (learning-to-rank.adoc, line 788). It is not changed here; a follow-up can update it on request.
