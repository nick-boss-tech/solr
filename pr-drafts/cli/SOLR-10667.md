## What happens today

**The full Solr distribution does not include the Learning To Rank example files.**

The packaging task copies each module's files into the distribution, but it has no step for a module's `example` directory. Only the Learning To Rank module has one today. It holds seven tracked files, among them config.json, train_and_upload_demo_model.py and exampleFeatures.json, and none of them reaches the distribution.

Pre-change code, at the base commit (the merge-base): [gradle/solr/packaging.gradle lines 80-102](https://github.com/nick-boss-tech/solr/blob/cabedd1d968059215188f4e7563fb303241899ed/gradle/solr/packaging.gradle#L80-L102).

## What this change does

**The packaging task copies each module's `example` directory into the distribution, except the `solrclient` folder the build generates.**

The change adds a `from` block to the packaging task. It copies the module's `example` directory to `example` in the distribution and leaves out `solrclient/`. The Learning To Rank build writes that folder into the example directory, and the example's `.gitignore` lists it. Copying the whole directory would ship build output and make the distribution depend on what sits in a developer's working tree: [gradle/solr/packaging.gradle lines 83-86](https://github.com/nick-boss-tech/solr/blob/9ce9ef1db5e9d33312ac628d2e3f0b236a474c36/gradle/solr/packaging.gradle#L83-L86).

The copy applies to every module, so a module that adds an example directory later ships it too.

## Proof

**The distribution now has the example files, leaves out the generated folder, and the new packaging check passes.**

On the base distribution (cabedd1d968), `modules/ltr/example` is absent, checked 2026-10-11. With a marker file placed in `solrclient/` in the example directory, a distribution assembled at 1e3f022552be, before this change, contains `modules/ltr/example/solrclient`. At this head, with the same marker, the folder is absent. The example files are present: config.json, train_and_upload_demo_model.py, exampleFeatures.json, README.md, libsvm_formatter.py and user_queries.txt. The hidden `.gitignore` file does not appear in the assembled distribution.

The new check is "ltr module ships its example directory" in [solr/packaging/test/test_modules.bats lines 42-47](https://github.com/nick-boss-tech/solr/blob/9ce9ef1db5e9d33312ac628d2e3f0b236a474c36/solr/packaging/test/test_modules.bats#L42-L47). At this head it runs 1 test with 0 failures.

Verified 2026-10-13 at head `9ce9ef1db5`. The distribution was assembled with the full-distribution install task. No Java code changed, so no Java test ran.

## Limits

**The check covers file presence in the full distribution only.**

- The check looks for three file names. It does not run the example's scripts or check their contents.
- The exclusion names only `solrclient/`. Another generated folder added to an example directory later would need its own exclusion.
- No check covers a module that adds an example directory later.
- The Learning To Rank reference page still says the example folder is not shipped in the binary release ([learning-to-rank.adoc, line 788](https://github.com/nick-boss-tech/solr/blob/9ce9ef1db5e9d33312ac628d2e3f0b236a474c36/solr/solr-ref-guide/modules/query-guide/pages/learning-to-rank.adoc#L788)). It is not changed here; a follow-up can update it on request.
