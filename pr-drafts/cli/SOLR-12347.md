## What happens today

**A node that needs more than 180 seconds to stop is forcefully killed by default.**

At the base commit b6b2b8f10e (the branch's merge-base), the default stop wait is 180 seconds: [solr/bin/solr line 154](https://github.com/nick-boss-tech/solr/blob/b6b2b8f10e9827e3b86e44649fb7966ce646c185/solr/bin/solr#L154). The same base commit's [Control Script Reference, line 400](https://github.com/nick-boss-tech/solr/blob/b6b2b8f10e9827e3b86e44649fb7966ce646c185/solr/solr-ref-guide/modules/deployment-guide/pages/solr-control-script-reference.adoc#L400), says the command kills the process after 180 seconds.

## What this change does

**The default stop wait is now 600 seconds. The start wait keeps its 180-second default.**

- Start scripts: [solr/bin/solr lines 154-155](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/solr#L154-L155). The start wait follows the stop wait only when the stop wait is set, and is 180 otherwise.
- Windows script: [solr.cmd lines 823-825](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/solr.cmd#L823-L825).
- Commented examples: [solr.in.sh](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/solr.in.sh#L27-L32) and [solr.in.cmd](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/solr.in.cmd#L31).

Behavior change: a `solr stop` with no `SOLR_STOP_WAIT` set now waits up to 600 seconds before it forces the stop. A `SOLR_STOP_WAIT` set by the user still sets the start wait, as before.

## A choice to check

**Should the default stay at 180 seconds, with the variable documented instead?**

The options: keep 180 seconds and document `SOLR_STOP_WAIT`; use 600 seconds, which this change implements; or use a longer value such as 900 or 1200 seconds. At 180 seconds, a node that takes longer to stop is forcefully stopped. A longer default means a stuck node waits longer before the forced stop.

Was 600 seconds the right default for this change?

## Limits

**The test runs the shell script only, and it does not check the start-wait default.**

- The Windows script changed, but it was not run. Its wait is cut by 5 percent for waits of 30 seconds or more, so the effective Windows wait is about 570 seconds ([solr.cmd lines 1308-1311](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/solr.cmd#L1308-L1311)).
- The test checks the 600-second stop message, and that an explicit 45-second stop wait sets the start message. It does not check the 180-second start default.
- The systemd unit still sets [`TimeoutSec=180s`](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/bin/systemd/solr.service#L32). It was not changed, so under systemd a stop may end at 180 seconds.
- The Control Script Reference still says 180 seconds ([line 400](https://github.com/nick-boss-tech/solr/blob/56d38389c75a39223f9b31e97671bb27d45ba99c/solr/solr-ref-guide/modules/deployment-guide/pages/solr-control-script-reference.adoc#L400)). It was not updated here.
