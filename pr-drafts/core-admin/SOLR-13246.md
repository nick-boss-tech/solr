## What happens today

**The debug line for a new searcher prints the whole searcher description, which can run to tens of kilobytes on a large index.**

[`QuerySenderListener.newSearcher`](https://github.com/apache/solr/blob/97d973814336101e12475558d7419321c743de79/solr/core/src/java/org/apache/solr/core/QuerySenderListener.java#L48) logs the searcher object itself. Its `toString()` appends the reader description. The ticket reports a single message above 20 KB, against Solr 7.7.

## What this change does

**The debug line logs only the searcher name. The message text is otherwise unchanged.**

A new public method, `SolrIndexSearcher.getSearcherName()`, returns the searcher's existing name field ([lines 562-568](https://github.com/nick-boss-tech/solr/blob/6817c6c0c267d127e82e4a679245040f5ca9db64/solr/core/src/java/org/apache/solr/search/SolrIndexSearcher.java#L562-L568)). The debug call uses it and sits inside an `isDebugEnabled()` check ([lines 50-52](https://github.com/nick-boss-tech/solr/blob/6817c6c0c267d127e82e4a679245040f5ca9db64/solr/core/src/java/org/apache/solr/core/QuerySenderListener.java#L50-L52)). The name has the form `Searcher@...[core] main`, so the message still names the searcher instance.

## Proof

**`TestQuerySenderNoQuery` passes 4 of 4 at head `6817c6c0c267`. The new `testDebugLogNamesSearcherWithoutDumpingReader` fails on the base code, where the message contains the reader description.**

`TestQuerySenderNoQuery`: 4 of 4 at `6817c6c0c267`, checked 2026-10-06. The new test ([lines 60-78](https://github.com/nick-boss-tech/solr/blob/6817c6c0c267d127e82e4a679245040f5ca9db64/solr/core/src/test/org/apache/solr/core/TestQuerySenderNoQuery.java#L60-L78)) reads the debug message, checks that it names the searcher, and checks that it does not contain `DirectoryReader`. On the base code the message includes the reader text, so the last check fails.

## Limits

- Only the `QuerySenderListener` debug line changes. Other log lines that print a searcher object keep their output, for example the error line in [`SolrCore`](https://github.com/nick-boss-tech/solr/blob/6817c6c0c267d127e82e4a679245040f5ca9db64/solr/core/src/java/org/apache/solr/core/SolrCore.java#L2823).
- `getSearcherName()` is a new public method on `SolrIndexSearcher`.
- The log level and the message prefix are unchanged.
