## What happens today

**`show=all` returns the index and fields sections, but no schema section.**

The ticket asks for `show=all` to populate the index, fields and schema sections. In [`handleRequestBody`](https://github.com/nick-boss-tech/solr/blob/5bac95376cd488678290d45b8a7a4c9ed2f089cd/solr/core/src/java/org/apache/solr/handler/admin/LukeRequestHandler.java#L235-L238), the `all` style falls into the same branch as the default, and that branch adds only the fields section. A 2018 comment on the ticket reports that `show=all` still does not work.

## What this change does

**`show=all` now adds the schema section after the fields section.**

When the style is `all`, the default branch also calls `getSchemaInfo`, the same call `show=schema` uses ([lines 239-241](https://github.com/nick-boss-tech/solr/blob/5bac95376cd488678290d45b8a7a4c9ed2f089cd/solr/core/src/java/org/apache/solr/handler/admin/LukeRequestHandler.java#L239-L241)). The index and fields output does not change. The `show=all` response grows by the schema section, which can be large on a big schema.

For distributed requests, the shard requests carry the same parameters, and the existing merge already copies the schema section from the first shard response ([lines 412-415](https://github.com/nick-boss-tech/solr/blob/5bac95376cd488678290d45b8a7a4c9ed2f089cd/solr/core/src/java/org/apache/solr/handler/admin/LukeRequestHandler.java#L412-L415)). That merge is not changed.

## Proof

`LukeRequestHandlerTest`: 10 of 10 at `5bac95376cd4`, checked 2026-10-06. The other new test, `testShowIndexOmitsFieldsAndSchema`, passes on both.

## Limits

**The distributed path was read but not run, and a document id still returns `BAD_REQUEST`.**

- `show=all` with a document id still returns `BAD_REQUEST`, as before. The document branch runs first and rejects any style other than `doc` ([lines 215-218](https://github.com/nick-boss-tech/solr/blob/5bac95376cd488678290d45b8a7a4c9ed2f089cd/solr/core/src/java/org/apache/solr/handler/admin/LukeRequestHandler.java#L215-L218)).
- The distributed path was read, not run. No test covers `show=all` across shards.
- The schema section has the same content as `show=schema`. This change does not alter that content.
