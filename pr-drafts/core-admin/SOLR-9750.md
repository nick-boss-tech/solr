## What happens today

**The implicit `/graph` handler reads its defaults from a paramset named `_ADMIN_GRAPH`, which does not follow the naming rule of the other implicit handlers.**

Each implicit handler names its paramset after its endpoint. The path is upper-cased and slashes become underscores. For example, [`/admin/segments` uses `_ADMIN_SEGMENTS`](https://github.com/nick-boss-tech/solr/blob/14c7aac0d151402b00259e2fb9bf5eed7049ec5d/solr/core/src/resources/ImplicitPlugins.json#L70) and [`/export` uses `_EXPORT`](https://github.com/nick-boss-tech/solr/blob/14c7aac0d151402b00259e2fb9bf5eed7049ec5d/solr/core/src/resources/ImplicitPlugins.json#L86). The [`/graph` entry](https://github.com/nick-boss-tech/solr/blob/14c7aac0d151402b00259e2fb9bf5eed7049ec5d/solr/core/src/resources/ImplicitPlugins.json#L97) uses `_ADMIN_GRAPH`. The [reference guide page](https://github.com/nick-boss-tech/solr/blob/14c7aac0d151402b00259e2fb9bf5eed7049ec5d/solr/solr-ref-guide/modules/configuration-guide/pages/implicit-requesthandlers.adoc#L471) repeats the same wrong name.

## What this change does

**The `/graph` handler now reads the `_GRAPH` paramset.**

The change edits one value in [ImplicitPlugins.json](https://github.com/nick-boss-tech/solr/blob/f97da6da14aafc1667fff59f279b404843598a00/solr/core/src/resources/ImplicitPlugins.json#L97) and the matching line in the [reference guide](https://github.com/nick-boss-tech/solr/blob/f97da6da14aafc1667fff59f279b404843598a00/solr/solr-ref-guide/modules/configuration-guide/pages/implicit-requesthandlers.adoc#L471). Anyone who set `/graph` defaults under `_ADMIN_GRAPH`, in `params.json` or through the Config API, must rename that paramset to `_GRAPH`. The change keeps no alias for the old name.

## Proof

**A new test fails on the base code and passes with this change.**

`TestImplicitPlugins` 2 of 2 pass at head `f97da6da14aa`, verified 2026-10-05. On the base code, `testGraphHandlerParamsetName` fails because the `/graph` value is `_ADMIN_GRAPH` where `_GRAPH` is expected. The other test in the class passes on both. The focused run at this head also covers `TestSolrConfigHandler` (8) and `TestReqParamsAPI` (1). All 11 pass.

## A choice to check

**The branch renames the paramset outright. The other route reads `_ADMIN_GRAPH` as a fallback for one release.**

The fallback keeps existing configs working, but it adds a second name to support. Was a plain rename the right call?

## Limits

**The change touches only the `/graph` paramset name.**

- No other implicit paramset is renamed.
- The new test reads `ImplicitPlugins.json` and checks the value. It does not send a request to `/graph`.
- Configs that use `_ADMIN_GRAPH` need the rename described above.
