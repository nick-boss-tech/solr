## What happens today

**`SolrQuery.getCopy()` does not copy the sort clauses, so the copy loses its sorts.**

`getCopy()` copies the query parameters, including the `sort` parameter. It does not copy the list of sort clauses ([SolrQuery.java L1182-L1188 at base](https://github.com/nick-boss-tech/solr/blob/14c7aac0d151402b00259e2fb9bf5eed7049ec5d/solr/solrj/src/java/org/apache/solr/client/solrj/request/SolrQuery.java#L1182-L1188)). Adding a sort to the copy then rewrites `sort` with only the new clause. `getSorts()` on the copy returns an empty list. The ticket lists 4.8.1, 6.3, 7.7, and 9.0 as affected versions.

## What this change does

**`getCopy()` also copies the sort clause list.**

- The copy gets a new list that holds the same `SortClause` objects ([SolrQuery.java L1187-L1189](https://github.com/nick-boss-tech/solr/blob/0fdc9e97b2b0930641f1d4174e6053c69895e4d3/solr/solrj/src/java/org/apache/solr/client/solrj/request/SolrQuery.java#L1187-L1189)). `SortClause` has final fields, so sharing the objects is safe. Changing the copy's sorts does not change the original.
- The copy's `getSorts()` now matches the original's. Nothing else in `getCopy()` changes.

## Proof

**One new test fails on the base code and passes with the change. All 27 focused tests pass at this head.**

- `SolrQueryTest` 19 of 19 at `0fdc9e97b2b0930641f1d4174e6053c69895e4d3`. The new `testGetCopyKeepsSortClauses` fails on the base code at its first comparison, because the copy's sorts are empty, and `testGetCopyRemoveReplaceAndClearSortClauses` fails there too. The other 17 tests pass on the base code and with the change, including `testGetCopyWithoutSortClauses`, which pins the no-sort case.
- `QueryRequestTest` 5 of 5 and `TestUpdateRequest` 5 of 5 at the same head.
- Verified 2026-10-15 at `0fdc9e97b2b0930641f1d4174e6053c69895e4d3`.

## Limits

**The new test covers a copy with two sorts.**

- A copy of a query with no sorts keeps a null list, as before; `testGetCopyWithoutSortClauses` covers that case.
- No other copy method in `SolrQuery` changed.
