## What happens today

**The ticket reports that an update without credentials can get through a `CloudSolrClient` under basic auth. The base code refuses that update in the test below.**

The reporter could still add documents through a `CloudSolrClient` with no credentials set. Queries and commits without credentials were refused. An update through a plain HTTP client was refused as expected.

## What this change does

**It adds one test block, and it changes no production code.**

The new block sends a batch of 30 documents with no credentials through the cluster's `CloudSolrClient`. It expects a `SolrException` with HTTP code 401 ([lines 248-260 at the head](https://github.com/nick-boss-tech/solr/blob/cdd265168a2adc76fb788f3d1f5587a3eee05e42/solr/core/src/test/org/apache/solr/security/BasicAuthIntegrationTest.java#L248-L260)). The block sits inside the existing `testBasicAuth` method.

## Proof

**The new check passes on this head and on the base code, so it pins behavior that already exists.**

- `BasicAuthIntegrationTest`, method `testBasicAuth`: 1 test run, 0 failures, 0 errors, 0 skipped at head `cdd265168a2a` (checked 2026-10-11).
- Base production code at `cabedd1d968`, with the head test file copied in: 1 test run, 0 failures, 0 errors, 0 skipped (checked 2026-10-11).
- The refusal arrives as a `SolrException` with code 401 at both trees.

This is a pin, not a fix. The test does not fail on the base code, so it does not show that this change fixes a bug. It records that the current code refuses the update, so a later change that admits the update would fail this test.

## Limits

**The check covers one request shape, and it does not check that nothing was written.**

- The test checks the refusal, not the document count. It does not show that no document was written.
- Standalone mode is not covered. No test in this change sends a no-credentials HTTP update in standalone mode. Standalone has no internal PKI path, so this is a coverage gap rather than a known hole.
- Solr clients that run inside a node were not reviewed for the same path.
- The reporter's attached test class is not part of this change. The test was written for this change.
