## What happens today

**Three collection APIs fail when a comma-separated list repeats a name or has a space before a name.**

CLUSTERSTATUS `shard`, BALANCE_REPLICAS `nodes`, and MIGRATE_REPLICAS `sourceNodes` and `targetNodes` split the list with `Set.of`, which throws `IllegalArgumentException` on a repeat ([ClusterStatus.java](https://github.com/nick-boss-tech/solr/blob/97d973814336101e12475558d7419321c743de79/solr/core/src/java/org/apache/solr/handler/admin/ClusterStatus.java#L171)). A space before a name matches no shard, so CLUSTERSTATUS says "not found" ([ClusterStatus.java](https://github.com/nick-boss-tech/solr/blob/97d973814336101e12475558d7419321c743de79/solr/core/src/java/org/apache/solr/handler/admin/ClusterStatus.java#L257-L260)). Links go to the merge-base, the code before this change.

## What this change does

**Each name is trimmed, blanks are dropped, and a repeat is kept once. A blank-only value now means an omitted one.**

The parsers are in [ClusterStatus.java](https://github.com/nick-boss-tech/solr/blob/cbf0c678f277d6f50d75408d4889d3b664469905/solr/core/src/java/org/apache/solr/handler/admin/ClusterStatus.java#L173-L180), [BalanceReplicasCmd.java](https://github.com/nick-boss-tech/solr/blob/cbf0c678f277d6f50d75408d4889d3b664469905/solr/core/src/java/org/apache/solr/cloud/api/collections/BalanceReplicasCmd.java#L52-L58), and [MigrateReplicasCmd.java](https://github.com/nick-boss-tech/solr/blob/cbf0c678f277d6f50d75408d4889d3b664469905/solr/core/src/java/org/apache/solr/cloud/api/collections/MigrateReplicasCmd.java#L142-L147). Blank input that used to fail now behaves differently:

- CLUSTERSTATUS with a blank `shard` returns all shards, not "not found."
- BALANCE_REPLICAS with a blank `nodes` uses all live data nodes. It used to fail with "Cannot balance across a single node" ([BalanceReplicasCmd.java](https://github.com/nick-boss-tech/solr/blob/97d973814336101e12475558d7419321c743de79/solr/core/src/java/org/apache/solr/cloud/api/collections/BalanceReplicasCmd.java#L62-L65)). A list that repeats one node now gets that message, not a server error.
- MIGRATE_REPLICAS with a blank `targetNodes` uses all other live nodes. A blank `sourceNodes` now fails with "sourceNodes is a required param."

## Proof

**The new check fails on the base code with a duplicate-element error and passes with this change.**

`TestCollectionAPI` passes 4 of 4 at head `cbf0c678f277`, verified 2026-10-13. The new method, `clusterStatusWithRepeatedShard`, checks an exact repeat and a repeat with a space ([TestCollectionAPI.java](https://github.com/nick-boss-tech/solr/blob/cbf0c678f277d6f50d75408d4889d3b664469905/solr/core/src/test/org/apache/solr/cloud/api/collections/TestCollectionAPI.java#L318-L324)).

On the base code (merge-base `97d973814336`, with the branch's test file at head `cbf0c678f277` in place), verified 2026-10-13, `TestCollectionAPI` runs 4 tests with 1 failure. The failure is the exact repeat, `shard=shard1,shard1`. The server rejects it with an IllegalArgumentException: duplicate element: shard1. The run stops at that check, so the space-padded check is not reached on base.

## A choice to check

**A blank node list now starts a rebalance across all live nodes, as an omitted one does.**

The other route keeps the failure for a list with no names. This change follows the rule for an omitted `nodes` value. The cost is that a blank value can now move replicas. Was it right to let a blank `nodes` value mean all live nodes?

## Limits

**Escaping is not added. Only CLUSTERSTATUS has a direct test, and only the exact repeat is run on base.**

- The ticket's core case, a value with a comma inside, still splits there. `StrUtils.splitSmart` already exists. A follow-up ticket and pull request can add escaping if you want it.
- The space-padded case is not shown failing on the base code by any run. Its base behavior is read from the code: the untrimmed name is looked up as is, and no shard matches it ([ClusterStatus.java L171 and L257-L260 at the merge-base](https://github.com/nick-boss-tech/solr/blob/97d973814336101e12475558d7419321c743de79/solr/core/src/java/org/apache/solr/handler/admin/ClusterStatus.java#L257-L260)).
- BALANCE_REPLICAS and MIGRATE_REPLICAS have no direct test for these inputs.
