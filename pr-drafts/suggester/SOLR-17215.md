## What happens today

**A suggester built on one replica answers only on that replica. Other replicas fail with a bare IllegalStateException.**

The reporter runs Solr 8.11.2 in SolrCloud, with three replicas on three nodes and a `FreeTextLookupFactory` suggester. Autocomplete works only on the replica where `/suggest?suggest.buildAll=true` ran. Other replicas fail with `java.lang.IllegalStateException: Lookup not supported at this time`.

The base code has no catch in `getSuggestions` ([base code](https://github.com/nick-boss-tech/solr/blob/cabedd1d968059215188f4e7563fb303241899ed/solr/core/src/java/org/apache/solr/spelling/suggest/SolrSuggester.java#L220-L234)).

## What this change does

**A suggester that is not built on a node now answers 503 with a clear message.**

- A catch around the lookup converts other `IllegalStateException`s. An `AlreadyClosedException` passes through unchanged, so a closed lookup is not reported as "not built" ([SolrSuggester.java](https://github.com/nick-boss-tech/solr/blob/04d35df186ddeab079ed93fce15c6fc61554912a/solr/core/src/java/org/apache/solr/spelling/suggest/SolrSuggester.java#L230-L237)). Lucene's and Solr's `AlreadyClosedException` both extend `IllegalStateException`.
- The 503 also covers `AnalyzingInfixSuggester`, which throws "suggester was not built" when unbuilt. Fuzzy lookups return empty when unbuilt and are not affected.
- The message names the suggester, keeps the original error, says dictionaries are not replicated, and gives the fix: build on every node, or enable `buildOnStartup` or `buildOnCommit` ([SolrSuggester.java](https://github.com/nick-boss-tech/solr/blob/04d35df186ddeab079ed93fce15c6fc61554912a/solr/core/src/java/org/apache/solr/spelling/suggest/SolrSuggester.java#L240-L248)). The ref guide adds the same point as a note ([suggester.adoc](https://github.com/nick-boss-tech/solr/blob/04d35df186ddeab079ed93fce15c6fc61554912a/solr/solr-ref-guide/modules/query-guide/pages/suggester.adoc#L199-L201)).

## Limits

**The guard has no test of its own, and replication is not added.**

- A closed lookup in the middle of a query is not practical to simulate in this test shape.
- The ticket title reports that replication does not work for suggesters. A comment on the ticket from 2024-12-20 says suggesters have never supported it.
