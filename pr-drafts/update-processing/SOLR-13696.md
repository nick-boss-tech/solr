## What happens today

**The Category and Dimensional routed-alias update tests are skipped. When the skip is removed, they fail in several places.**

Both suites extend `RoutedAliasUpdateProcessorTest`, which was skipped for this ticket. When the skip is removed:

- The create-alias message for a dimensional alias has no top-level router name or field. The Dimensional suite cannot create its alias.
- The Dimensional tests use a fixed "future" date, 2020-10-23. That date is now in the past. The router then creates daily collections toward it until the client times out.
- The final placement check reads `[shard]` in its default style. At luceneMatchVersion 9.5 that style returns a bare shard id. The id holds neither the category nor the day the check asserts.
- A document whose timestamp is still a string at update-processor time throws `ClassCastException` in `TimeRoutedAlias.formattedRouteValues`. The create-alias failure stops the suite before it gets that far.
- Each test method creates its own cluster, but only the last one is shut down. The earlier clusters leak and cause teardown failures.

## What this change does

**The two suites run again, their tests are repaired, and two production defects are fixed.**

- The `@AwaitsFix` on the base class is removed, so the Category and Dimensional suites run in normal mode. The base class keeps its `@Ignore`, since it is abstract ([base class](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/RoutedAliasUpdateProcessorTest.java#L67)).
- `addDocsAndCommit` commits each collection of the alias explicitly and no longer relies on commitWithin ([commit loop](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/RoutedAliasUpdateProcessorTest.java#L360-L370)).
- Each test method shuts down its own cluster in an `@After` method ([L72-L82](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/RoutedAliasUpdateProcessorTest.java#L72-L82)).
- The category test now uses `ship_name_s` instead of `ship_name_en` ([L53](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/CategoryRoutedAliasUpdateProcessorTest.java#L53)).
- The "future" document is built 30 days after the current time ([helper](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/DimensionalRoutedAliasUpdateProcessorTest.java#L615-L621)). The placement check asks for `[shard]` in URL style ([L282-L293](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/update/processor/DimensionalRoutedAliasUpdateProcessorTest.java#L282-L293)).
- Create-alias fix: for a dimensional alias, the message now carries the top-level router name, in the `Dimensional[TIME,CATEGORY]` form, and the comma-joined router field. That is the shape SolrJ already sends ([CreateAlias](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/java/org/apache/solr/handler/admin/api/CreateAlias.java#L128-L141), [SolrJ](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/solrj/src/java/org/apache/solr/client/solrj/request/CollectionAdminRequest.java#L2326-L2327)). The change applies to every dimensional alias created through the create-alias API, not only in tests. `CreateAliasAPITest` now expects 12 entries, up from 10, and checks both new keys ([L308-L311](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/test/org/apache/solr/handler/admin/api/CreateAliasAPITest.java#L308-L311)).
- Time-route fix: `formattedRouteValues` parses the value with `parseRouteKey` instead of casting it to `Date` ([L219-L225](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/java/org/apache/solr/cloud/api/collections/TimeRoutedAlias.java#L219-L225), [parseRouteKey](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/java/org/apache/solr/cloud/api/collections/TimeRoutedAlias.java#L468-L479)). A string timestamp is now parsed. Only dimensional aliases call this method ([caller](https://github.com/nick-boss-tech/solr/blob/da4fa6df11784ce5a83bc7e74ec7b6aa78f689b9/solr/core/src/java/org/apache/solr/cloud/api/collections/DimensionalRoutedAlias.java#L120-L124)).
