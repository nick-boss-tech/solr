## What happens today

**Field mutating update processors skip child documents, so child fields keep the values they were sent with.**

These processors change only the fields of the root document. Child documents are skipped, both anonymous children and child documents given as a field value. So a trim, regex replace, remove-blank or date parse step does not run on a child's field.

## What this change does

**Child documents given as a field value are changed only under a field the selector names. Anonymous child documents are always walked.**

- Under a selected field, each child document in the field value is walked at any depth, and the selector decides which of its fields change ([gated descent](https://github.com/nick-boss-tech/solr/blob/5e2317443f4116a9e97330b0d6ce175cf44b54df/solr/core/src/java/org/apache/solr/update/processor/FieldMutatingUpdateProcessor.java#L128-L145)). Under an unselected field, the child is left alone.
- Anonymous child documents are walked at any depth ([anonymous walk](https://github.com/nick-boss-tech/solr/blob/5e2317443f4116a9e97330b0d6ce175cf44b54df/solr/core/src/java/org/apache/solr/update/processor/FieldMutatingUpdateProcessor.java#L148-L153)). The selector still decides which field names change inside each child.
- A document reachable by two paths is changed once, since not every mutation is safe to repeat ([identity check](https://github.com/nick-boss-tech/solr/blob/5e2317443f4116a9e97330b0d6ce175cf44b54df/solr/core/src/java/org/apache/solr/update/processor/FieldMutatingUpdateProcessor.java#L90-L95)).
- Upgrade note: after upgrading, pipelines that send child documents will see these processors change child field values. Examples are trim, regex replace, remove-blank and date parsing. Check the chains that send child documents before upgrading.

## A choice to check

**The other route leaves anonymous child documents alone, as before.**

Anonymous child documents have no field name for the selector to match. Leaving them alone would keep today's output for pipelines that send them. This branch walks them instead, and the upgrade note above applies to them.

Was the wider walk into anonymous child documents the right semantics?
