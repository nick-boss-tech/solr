## What happens today

**A language identifier outside the processor package cannot build the results it must return.**

`DetectedLanguage` has a package-private constructor ([DetectedLanguage.java](https://github.com/nick-boss-tech/solr/blob/e4c878627108ee2347cb1d5ee915e3e953c4249f/solr/modules/langid/src/java/org/apache/solr/update/processor/DetectedLanguage.java#L24)). `LanguageIdentifierUpdateProcessor` declares `protected abstract List<DetectedLanguage> detectLanguage(Reader)` ([LanguageIdentifierUpdateProcessor.java](https://github.com/nick-boss-tech/solr/blob/e4c878627108ee2347cb1d5ee915e3e953c4249f/solr/modules/langid/src/java/org/apache/solr/update/processor/LanguageIdentifierUpdateProcessor.java#L345)). A subclass in another package can override that method, but it cannot create the `DetectedLanguage` values it returns. Both in-tree subclasses sit in the processor package ([LangDetect](https://github.com/nick-boss-tech/solr/blob/e4c878627108ee2347cb1d5ee915e3e953c4249f/solr/modules/langid/src/java/org/apache/solr/update/processor/LangDetectLanguageIdentifierUpdateProcessor.java#L40), [OpenNLP](https://github.com/nick-boss-tech/solr/blob/e4c878627108ee2347cb1d5ee915e3e953c4249f/solr/modules/langid/src/java/org/apache/solr/update/processor/OpenNLPLangDetectUpdateProcessor.java#L41)).

## What this change does

**The `DetectedLanguage` constructor becomes public. Nothing else changes.**

The constructor is now `public DetectedLanguage(String lang, Double certainty)` ([DetectedLanguage.java](https://github.com/nick-boss-tech/solr/blob/e4c878627108ee2347cb1d5ee915e3e953c4249f/solr/modules/langid/src/java/org/apache/solr/update/processor/DetectedLanguage.java#L24)). The class, its fields, and its getters stay as they are. Access is only widened, so no existing caller changes.

## A choice to check

**The open question is the access level of the constructor.**

Options considered:

- Keep the constructor package-private. A custom processor outside the package stays unable to build results.
- Make it `protected`. A protected constructor is reachable only from the same package and from subclasses of `DetectedLanguage`. A custom processor extends `LanguageIdentifierUpdateProcessor`, so it cannot reach a protected constructor.
- Make it `public`, as implemented. This adds public API to the langid module.

Was a public constructor the right call for this API?
