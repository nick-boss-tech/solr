## What happens today

**An interrupt while a commit waits for the new searcher is logged as an error.**

A commit with `waitSearcher` waits for the new searcher to register. If the waiting thread is interrupted, the base code logs `Exception waiting for searcher` at ERROR, with a stack trace. The interrupt status is cleared, and the commit then returns normally. The same block also handles a failed searcher registration, so both cases were logged the same way.

## What this change does

**An interrupted wait is logged at INFO and the interrupt status is restored. The commit still returns normally.**

- The wait moves into a package-private helper, `awaitSearcher` ([DirectUpdateHandler2.java#L951-L960](https://github.com/nick-boss-tech/solr/blob/db357868610b92709335129ebada4646ecf11e26/solr/core/src/java/org/apache/solr/update/DirectUpdateHandler2.java#L951-L960)). It is called from the commit path at [#L943](https://github.com/nick-boss-tech/solr/blob/db357868610b92709335129ebada4646ecf11e26/solr/core/src/java/org/apache/solr/update/DirectUpdateHandler2.java#L943).
- On an interrupt, the helper restores the interrupt status and logs at INFO. A failed registration (`ExecutionException`) is still logged at ERROR.
- When the wait is interrupted, `commit` returns normally, as it did on base. The new searcher may not be registered yet when it returns.
- There is no public API change.

## A choice to check

**Return normally after an interrupted wait, or report the interrupt to the caller as an error.**

The implemented route returns normally and restores the interrupt status. The alternative reports the interrupt as an error, so the commit would not return success in that case. Was returning normally the right call?

## Limits

**The commit-level test is the weak point, and two test classes cover a small change.**

- The commit-level test is timing-sensitive. It relies on a single-threaded searcher executor and short joins, and it has not been checked for seed sensitivity.
- Two test classes cover a small change. A maintainer may prefer one of them.
