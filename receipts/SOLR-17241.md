## PR description draft (not posted)

SOLR-17241: honor `wt` on v2 collection responses from nodes without a local replica.

A collection-scoped v2 request served by a node that hosts no replica runs without a `SolrQueryRequest`. `MediaTypeOverridingFilter` then read `wt` as null and kept the negotiated media type, and the javabin writer dereferenced the missing request and failed with a 500. The filter now reads the parsed parameters from the request context when no request is present, and `BaseMessageBodyWriter` supplies a base request built from those parameters, so the javabin writer can serialize the response.

Verified on JDK 21.0.12.1 with seed `17241C0FFEE17241` at `86d86e3d3e`: the filter test suite (8 methods) and the v2 integration suite (14 tests, including `testReloadHonorsWtOnNonHostingNode`) pass. With the parent filter, the filter test fails on the negotiated `text/plain`, and the reload test fails on the non-hosting node with the javabin/JSON mismatch. `:solr:core:check -x test` and root `check -x test` pass.
