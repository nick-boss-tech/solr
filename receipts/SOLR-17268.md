### Head failure group 1: non-numeric fixture ids against the standard schema's id copyFields

`JSONWriterTest.testArrntvFacetsOnDefaultJsonWriter` and `testXmlWriterIgnoresArrntv` fail while indexing their documents: `SolrException: ERROR: [doc=arrntv-1] Error adding field 'id'='arrntv-1' msg=For input string: "arrntv-1"` (likewise `arrntv-xml`), thrown at `DocumentBuilder.toDocument`. Cause: `JSONWriterTest` runs on the standard test schema (`solr/core/src/test-files/solr/collection1/conf/schema.xml`), where `id` is a StrField but the schema carries copyFields from `id` to `range_facet_l` (`*_l`, long), `id_i1` (`*_i1`, int), `range_facet_l_dv` (`*_l_dv`, long) and `range_facet_i_dv` (`*_i_dv`, int). Indexing a non-numeric id makes DocumentBuilder convert the id value for those numeric copyField targets, and the parse fails. The class's pre-existing tests use numeric id strings, so they never trip it. This is the same failure the earlier partial gate at `81f0c11487` recorded; it persists unchanged at the current tip. Consequences: `testArrntvFacetsOnDefaultJsonWriter` never reaches the writer at either head, and `testXmlWriterIgnoresArrntv` cannot act as a control until the fixture ids are numeric.
