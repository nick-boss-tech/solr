# SOLR-17911: Implement File Content Viewer Component (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds `FileContentViewer`, a Compose composable in `ui/shared` that shows a text file's content with line numbers.

- The content is a plain string.
- Line numbers sit in a gutter that is not selectable, so copying text does not copy numbers.
- The text is selectable for copy and paste.
- Line breaks and backslash escapes are shown as written.
- The view scrolls vertically and horizontally.

Out of scope, per the ticket: editing, syntax highlighting, wrapping, and font size.
