## PR description draft (not posted)

SOLR-18610: test the web identity credentials path under the shipped Security Manager policy.

The new test runs the AWS SDK web identity credentials provider in a child JVM with the Security Manager enabled and the shipped `server/etc/security.policy`. A local STS stub returns session credentials, and the test checks them. The parent test class keeps its existing Testcontainers configuration. The Apache 5 client used for STS needs three `jdk.net.NetworkPermission` grants for TCP keep-alive options; without them the provider fails under the Security Manager. Verified on JDK 21.0.12.1 with seed `18610C0DE`: the focused test passes with the grants and fails with the original policy for that permission.
