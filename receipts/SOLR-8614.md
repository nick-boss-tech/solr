## Design applied

- `SolrClient.setUseXmlFormat(boolean)` is a public no-op in the base class. Clients that do not send requests over HTTP ignore it.
- `HttpSolrClient` (and so `HttpJdkSolrClient` and `HttpJettySolrClient`) replaces its request writer and response parser.
- `CloudSolrClient` applies the toggle to its HTTP client and its LB client. `ConcurrentUpdateBaseSolrClient` and `CollectionScopedSolrClient` delegate to the client they wrap.
- `LBSolrClient` applies the toggle to its own writer and parser, and keeps the explicit choice. Each child client it uses for a request gets the same format before the request is sent, so a child built with a custom writer is overridden only after the caller has chosen a format explicitly.
- Not covered: clients that never send HTTP, which ignore the toggle by design.
